Module: User Management & Authentication
ID: US-001 As an Admin, I want to complete a one-time initial registration so that the primary system account is established.
ID: US-002 As a System, I want to deactivate the sign-up page after the first admin registers to prevent unauthorized admin accounts.
ID: US-003 As a User, I want to receive a PIN code via email during registration so that I can verify my identity before my account is activated. For the First Admin Account, a link will be emailed which when clicked will activate the account. The PIN will be emailed when an admin has to create a new account for an employee or client.
ID: US-004 As an Admin, I want to create new Employee or Admin accounts by entering their username and email so they can access the system. Admin will add Name and Email for new account registration. The new user will add their own username.
ID: US-005 As a New User, I want to receive an email with a setup link so that I can securely set my initial password.
ID: US-006 As a New User, I want to verify a PIN sent to my email after setting my password to finalize my account setup. This is not needed as registration is being completed using a setup link sent to email.
ID: US-007 As a User, I want to log in using my credentials and a two-factor PIN code so that my account remains secure.
ID: US-008 As an Admin, I want to trigger a "Reset Password" email for specific users so they can regain access if they forget their credentials.
ID: US-009 As a User, I want to change my password via a secure link without having to go through the full initial sign-up flow again.
ID: US-010 As an Admin, I want to add a new client by entering their business name, contact name, email, phone number, and address so they can be registered in the system.
ID: US-011 As a Client, I want to receive an automated email with a password setup link once the Admin adds me to the system.
